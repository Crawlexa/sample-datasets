# Crawlexa sample datasets

Schemas and **illustrative sample rows** for Crawlexa's standard eCommerce feeds, so you can see the exact shape of the data before a project starts.

> The rows here are synthetic examples that show the format. For real data from *your* target sites, request a **free 1,000-record sample**: [crawlexa.com](https://crawlexa.com) · sales@crawlexa.com

| Dataset | Files | Typical refresh |
|---|---|---|
| Product catalogue | [`ecommerce/products.csv`](ecommerce/products.csv), [`.json`](ecommerce/products.json) | Weekly |
| Competitor price monitoring | [`ecommerce/price_monitoring.csv`](ecommerce/price_monitoring.csv) | Daily |
| Field definitions | [`ecommerce/SCHEMA.md`](ecommerce/SCHEMA.md) | n/a |

Delivery options: CSV, JSON, Excel, Google Sheets, API, S3/GCS, Snowflake, BigQuery.
Public data only, collected within the scope agreed with each client.
